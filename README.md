# 💳 Digital Payment Fraud Detection

A Machine Learning project to detect fraudulent online transactions in India.

---

## 📌 Project Overview

This project uses a Digital Payment Fraud Detection dataset containing online transaction records from India. The goal is to classify transactions as Fraud or Legitimate using features like transaction amount, device type, location, and IP risk score.

---

## 📂 Dataset Features

| Feature | Description |
|---------|-------------|
| `transaction_amount` | Amount of the transaction |
| `payment_mode` | Mode of payment used |
| `device_type` | Device used for transaction |
| `location` | Transaction location |
| `account_age` | Age of the account |
| `login_attempts` | Number of login attempts |
| `ip_risk_score` | Risk score of IP address |
| `is_fraud` | 0 = Legitimate, 1 = Fraud |

---

## 🛠️ Tools & Libraries

- **Data Processing:** Pandas, NumPy, StandardScaler
- **Visualization:** Matplotlib, Seaborn
- **ML Models:** Scikit-Learn classifiers
